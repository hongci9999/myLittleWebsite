# D2 Hello world 위젯이 최신 글 대신 6월 글을 계속 표시

날짜: 2026-10-25

## 발생한 오류

메인 「최신 기술 콘텐츠」의 D2 Hello world 칸이 10월에 새 글(10/21·10/20·10/8…)이 올라왔는데도 2026-06-30 글(「AI 에이전트 회사 차리기」)을 계속 최신으로 보여 줬다.

## 원인

- `server/src/services/d2-helloworld-atom.ts`가 Atom 피드에서 카테고리 `hello world` 중 **본문에 네이버TV 영상(`tv.naver.com/embed`)이 있는 글만** 골랐다. 위젯을 처음 만들 때(Engineering Day 영상 위젯) 정한 조건이다.
- 최근 Hello world 글은 전부 영상 없는 텍스트 기사라 모두 걸러졌고, 영상이 있는 마지막 글이 남았다.
- 텍스트 기사를 넣자 요약이 빈칸이 되는 문제도 이어서 나왔다 — 첫 `<p>`가 이미지만 감싸고 있었다.

## 수정 방법

1. 영상 조건 제거 — 텍스트 기사도 포함. 텍스트 글은 본문 첫 이미지를 썸네일로, 재생 아이콘은 영상 글에만(`D2HelloWorldWidget`).
2. 요약은 첫 **비어 있지 않은** 문단을 쓴다.

## 결과/참고

- 배포 API `/api/d2-helloworld/latest`가 2026-10-21 「2026년과 이후 JavaScript의 동향 - 브라우저 밖의 JavaScript」를 요약과 함께 반환함을 확인.
- 서버 캐시 30분 — 새 글은 최대 30분 늦게 반영.
- 교훈: 외부 피드를 고를 때 **형식 조건(영상 유무)** 은 원본의 발행 방식이 바뀌면 조용히 「업데이트 안 됨」처럼 보인다. 조건이 꼭 필요한지, 걸러진 항목이 0이 되는지 확인할 것.
